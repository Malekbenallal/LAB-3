# Лабораторная работа 3 — рецепт по фото холодильника через Groq API

## 1. Что реализовано

Проект выполняет задание через реальную мультимодальную модель и не использует DEMO-режим.

Пайплайн:

1. Пользователь загружает фото холодильника, продуктовой полки или продуктов.
2. Groq Vision-модель распознаёт продукты на изображении.
3. LLM через Groq API генерирует 2–3 рецепта по списку найденных продуктов.
4. В интерфейсе есть фильтры: вегетарианское, время готовки, сложность, количество порций.
5. Для Eval есть 10 фото и файл `data/eval_expected.csv` с ручной разметкой.
6. Скрипт `evaluate.py` сравнивает ручную разметку с ответом модели и показывает, что модель пропустила и что придумала.

## 2. Что нужно установить

Нужно установить:

- Python 3.10 или новее;
- VSCode;
- Python-зависимости из `requirements.txt`.

Ollama не нужен. Нужен только действующий `GROQ_API_KEY`.

## 3. Как получить Groq API key

1. Зарегистрируйся или войди в аккаунт на `https://console.groq.com`.
2. Создай API-ключ.
3. Открой файл `.env`.
4. Вставь ключ в строку:

```text
GROQ_API_KEY=твой_ключ
```

В проекте по умолчанию используется модель:

```text
meta-llama/llama-4-scout-17b-16e-instruct
```

Эта модель подходит для изображений и может возвращать JSON.

## 4. Установка проекта в VSCode

Открой папку проекта `lr3_recipe_vlm_groq` в VSCode.

Создай виртуальное окружение:

```bash
python -m venv .venv
```

Активируй его на Windows:

```bash
.venv\Scripts\activate
```

На macOS/Linux:

```bash
source .venv/bin/activate
```

Установи зависимости:

```bash
pip install -r requirements.txt
```

## 5. Настройка `.env`

В проекте уже есть шаблон `.env`:

```text
PROVIDER=groq
GROQ_API_KEY=
GROQ_MODEL=meta-llama/llama-4-scout-17b-16e-instruct
GROQ_RECIPE_MODEL=meta-llama/llama-4-scout-17b-16e-instruct
```

Заполни только `GROQ_API_KEY`.

## 6. Запуск приложения

Запуск веб-интерфейса:

```bash
streamlit run app.py
```

Дальше в браузере:

1. Загрузи фото.
2. Нажми `1) Распознать продукты`.
3. Выбери фильтры.
4. Нажми `2) Сгенерировать рецепты`.
5. При необходимости сохрани результат в `outputs`.

## 7. Запуск через терминал

Пример:

```bash
python main.py --image data/eval_images/fridge_01.jpg --time 30 --difficulty легко --servings 2
```

С вегетарианским фильтром:

```bash
python main.py --image data/eval_images/fridge_02.jpg --vegetarian --time 20 --difficulty легко
```

## 8. Eval на 10 фото

В папке уже лежат 10 фото:

```text
data/eval_images/fridge_01.jpg
...
data/eval_images/fridge_10.jpg
```

Файл ручной разметки уже заполнен:

```text
data/eval_expected.csv
```

Запусти оценку:

```bash
python evaluate.py --expected data/eval_expected.csv --images-dir data/eval_images --out outputs/eval_results.csv
```

После выполнения появится файл:

```text
outputs/eval_results.csv
```

В нём будут колонки:

- `manual_expected_count` — количество продуктов в ручной разметке;
- `model_predicted_count` — количество продуктов, найденных моделью;
- `matched_count` — сколько продуктов совпало;
- `missed_by_model_count` — сколько продуктов модель пропустила;
- `invented_by_model_count` — сколько лишних продуктов добавила модель;
- `expected_products` — продукты, которые указаны вручную;
- `predicted_products` — продукты, которые нашла модель;
- `found` — совпавшие продукты;
- `missed_by_model` — продукты, которые модель пропустила;
- `invented_by_model` — продукты, которые модель придумала;
- `precision` — точность;
- `recall` — полнота;
- `f1_score` — F1-мера, среднее гармоническое precision и recall.

В конце `evaluate.py` выводит таблицу со средними значениями всех трёх метрик:

```text
Precision
Recall
F1-score
```

Также рядом с `outputs/eval_results.csv` сохраняются дополнительные файлы:

- `outputs/eval_results_manual_vs_model.csv` — таблица сравнения ручной разметки и ответа модели;
- `outputs/eval_results_manual_vs_model.png` — график количества продуктов в ручной разметке и в ответе модели;
- `outputs/eval_results_match_errors.png` — график совпавших, пропущенных и лишних продуктов;
- `outputs/eval_results_eval_curves.png` — общий график оценки в формате двух графиков рядом;
- `outputs/eval_results_metrics_summary.csv` — итоговая таблица средних метрик;
- `outputs/eval_results_metrics_by_image.png` — график precision, recall и F1-score по каждому изображению;
- `outputs/eval_results_metrics_summary.png` — график средних значений трёх метрик.

## 9. Возможные ошибки

### Ошибка `GROQ_API_KEY` не найден

Проверь файл `.env`. В нём должен быть записан твой ключ.

### Ошибка доступа к модели

Убедись, что у аккаунта есть доступ к модели `meta-llama/llama-4-scout-17b-16e-instruct`. Если нет, поменяй `GROQ_MODEL` и `GROQ_RECIPE_MODEL` на доступную модель в своём кабинете.

### Фото слишком большое

Groq принимает локальные фото как base64. Если запрос отклоняется из-за размера, уменьши фото до 1200–1600 px по ширине или сохрани его с меньшим качеством.
